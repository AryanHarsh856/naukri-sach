# 🔍 Naukri Sach — Verify Before You Trust

A free tool built to protect Indian freshers from fake job scams.

🌐 **Live Demo:** [Click Here](https://naukri-sach.vercel.app)

---

## 💡 The Problem

Fake job offers are destroying the careers and mental health of thousands of
Indian freshers every year. Scammers send convincing offer letters, ask for
registration fees, and disappear. There was no simple free tool to verify
job offers — so I built one.

---

## ✨ Features

- 🔍 **Job Offer Scanner** — Paste any job description and instantly detect red flags
- 📊 **Suspicion Score** — Get a score out of 100 based on danger level
- 🏢 **Company Search** — Check if a company has been reported as fake
- 🚩 **Community Reports** — Report fake companies to protect other freshers
- 💡 **Tips Section** — Learn how to spot fake job offers
- 📱 **Mobile Friendly** — Works on all devices

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 🚀 How to Run Locally

1. Clone this repository
2. Open index.html in your browser
3. That is it — no dependencies needed
